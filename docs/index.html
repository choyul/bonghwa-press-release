봉화군 보도자료 도우미 설치 안내

발표 자료나 기획안을 주면 봉화군 보도자료 문체로 초안을 쓰고, 공보팀 양식(hwpx)에 배포일자·제목·부제·본문을 채워 줍니다.

기사체 초안"봉화군은 ~했다고 밝혔다"로 시작하는 리드, 본문 6문단 안팎
확인 필요 항목배포일자, 명칭 확정, 코멘트 발언자 등을 따로 정리
양식 채우기공보팀 hwpx 양식에 바로 채운 파일 제공

Claude (웹·데스크톱 앱)

가장 확실한 방법입니다. 양식 채우기까지 모두 됩니다.

스킬 파일 내려받기 (zip)
  1. 위 버튼으로 zip 파일을 내려받습니다. 압축은 풀지 않습니다.
  2. Claude에서 Customize → Skills로 갑니다. 바로가기
  3. + → Create skill → Upload a skill을 누르고 zip 파일을 올립니다.
  4. 목록에 생긴 bonghwa-press-release를 켭니다.

설정에서 코드 실행 및 파일 생성이 켜져 있어야 합니다. 설치 후에는 "이 자료로 보도자료 써 줘"라고 하면서 자료와 양식을 첨부하면 됩니다.

Claude에 주소를 주고 설치하기

zip 내려받기가 번거로울 때 씁니다. 아래 문장을 Claude 대화창에 붙여 넣으세요.

https://github.com/choyul/bonghwa-press-release 저장소의
skill/bonghwa-press-release/SKILL.md 를 읽고 내 스킬로 설치해 줘.
  1. Claude가 저장소를 읽고 스킬 저장 카드를 띄우면 저장을 누릅니다.
  2. 양식을 채울 때는 스킬이 GitHub에서 양식 채우기 스크립트를 내려받아 씁니다.

Claude가 저장소를 열지 못하거나 저장 카드가 뜨지 않으면 Claude 탭의 zip 업로드 방법을 쓰세요.

ChatGPT (나만의 GPT)

초안 작성과 양식 채우기가 모두 됩니다. 코드 실행 기능을 켜야 합니다.

  1. ChatGPT 왼쪽 메뉴에서 GPT 탐색 → 만들기 → 구성 탭으로 갑니다.
  2. 이름에 봉화군 보도자료 도우미를 적습니다.
  3. 지침 칸에 아래 지침을 복사해 붙여 넣습니다.
    지침 원문 보기
  4. 지식에 아래 두 파일을 내려받아 올립니다.
    fill_hwpx.py SKILL.md
  5. 기능에서 코드 인터프리터 및 데이터 분석을 켜고 저장합니다. 공유 범위를 "링크가 있는 사람"으로 하면 동료도 같은 GPT를 쓸 수 있습니다.

GPT를 만들 수 없는 요금제라면 프로젝트를 만들어 같은 지침과 파일을 넣어도 됩니다.

Gemini (Gem)

초안과 양식 채우기용 JSON까지 만들어 줍니다. 양식 파일은 PC에서 스크립트로 채웁니다.

  1. Gemini 왼쪽 메뉴에서 Gem 관리자 → 새 Gem을 누릅니다.
  2. 이름에 봉화군 보도자료 도우미를 적습니다.
  3. 안내 칸에 지침을 붙여 넣습니다.
  4. 지식에 SKILL.md를 올리고 저장합니다.

Gem이 만들어 준 JSON을 내용.json으로 저장한 뒤, 파이썬이 있는 PC에서 실행합니다.

pip install lxml
python fill_hwpx.py --template 양식.hwpx --content 내용.json --out 보도자료_주제.hwpx

메뉴 이름과 요금제별 제공 여부는 서비스 업데이트에 따라 달라질 수 있습니다.

양식이 .hwp(구형 파일)일 때

공보팀 양식이 이전 보도자료 파일이면 대개 구형 .hwp입니다. 도우미는 .hwpx만 채울 수 있습니다.

  1. 한글에서 양식을 엽니다.
  2. 파일 → 다른 이름으로 저장에서 파일 형식을 HWPX로 골라 저장합니다.
  3. 저장한 .hwpx 파일을 도우미에게 첨부합니다.

결과 파일도 .hwpx로 나옵니다. .hwp가 필요하면 한글에서 다시 저장하면 됩니다. 본문 서체를 양식 기본값으로 통일하므로 줄바꿈 위치는 한글에서 한 번 확인하세요.
